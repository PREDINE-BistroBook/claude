## Scope

Wine Window tour only. No Pub Crawl footage, no generic "secret Florence" content as a standalone angle — Ash narrowed this on 2026-08-29 to the two sellable products. A "hidden local knowledge" beat is fine *inside* a Wine Window clip (e.g. "the window locals still use"), never as its own topic.

## Direction (Ash confirmed 2026-08-29): real footage, not AI-generated

**Real guide/guest phone footage is the default, not Higgsfield-generated video.** AI-generated clips read as AI-made to most viewers and actively hurt trust for a brand like this — confirmed by Ash and backed by the research on the Growth Playbook page. Do not call Higgsfield's video generation tools for the hero clip. If no usable real footage exists for a given week (see step 1), that is a blocked week to log per step 5, not a reason to fall back to synthetic generation.

## Steps

0. Check `#agent-wine-window` for anything Ash posted since the last run — an approval/reaction on a staged draft is handled here per step 4, anything else follows the normal rules.
1. Pick this week's sub-angle from real footage that exists or can be gotten without a new ask to guides (see guardrail below on what counts as "without a new ask"):
   - **Guest reaction clip** — a guide's phone footage of a genuine guest reaction (first sip, first sight of a window). Always leads the week when it exists.
   - **Guide POV, raw** — handheld, first-person, walking up to a window and telling its story on camera, unscripted-sounding.
   - **Window story, real footage** — phone-shot close-up on an actual wine window during a real tour, not a generated establishing shot.
2. Build the hook first, before editing anything else. Use one of the four patterns that are actually scoring in 2026 (see Growth Playbook): **Contrarian** ("everyone thinks X — they're wrong"), **Identity Call** ("if you've never heard of X, you're about to feel old"), **Confession** ("I've walked past this 200 times, then—"), or **Open Loop** ("this hole in the wall is older than your country"). Under 2 seconds, 8-15 words, delivered like you're interrupting the viewer mid-thought — bold on-screen text, not a slow reveal. Generate 3-5 hook variants for the same footage and pick the sharpest, don't settle for the first one.
3. **See the footage before cutting it — don't guess from audio alone.** Upload the candidate raw clip (`media_upload` + `media_confirm`) and run `video_analysis_create` for a real scene-by-scene read (visuals, not just what's said) before picking the exact cut points and hook. This has already caught a real beat an audio-only transcript missed once, on the Pub Crawl side (a visual sight-gag buried mid-clip) — don't skip it to save time. Keep the analysis clip short (under ~40s) for reliable results per that tool's own guidance.
3a. Edit using the `short-form-editing-craft` skill for pacing/timing judgment, and the `video-editing` (higgsedit) workflow tool for the actual cut/compose — real per-frame control, native text/graphics compositing, and far more reliable than hand-rolled ffmpeg drawtext. No synthetic B-roll, no AI voiceover standing in for a real one. If cutting from one long source is slow (HDR footage can make Chrome-engine seeking crawl), pre-trim each beat into its own short file with ffmpeg first, then compose those — much faster. Render the final pass with `higgsedit render --engine node` (roughly 4x faster than the default Chrome engine for footage) once graphics are proofed.
3b. **Sound effects:** there is no standalone SFX/music generation tool available here — `generate_audio` is speech-only (text-to-speech) and explicitly must not be used for SFX. A tasteful synthesized cue (e.g. a short tone/noise burst shaped with ffmpeg, paired with a quick on-screen flash) is a legitimate stand-in for a hit moment, but say plainly in the digest/Slack post that it's synthesized, not a real or licensed sound effect — never imply otherwise.
3c. **Before staging, run `virality_predictor`** on the finished cut (upload + confirm first; the tool caps input at 16s, so predict against a trimmed copy if the final cut runs longer, but stage the full-length edit to Ash). Report the scores (overall/hook/sustain) honestly in the Slack post — they're predictive proxies, not guarantees, but a low hook score with strong sustain is a real signal the opening 2 seconds needs another pass before spending Ash's review time on it.
4. **Stage, do not publish.** Post the draft(s) to `#agent-wine-window` for Ash's 👍, and also make the actual video file available directly (not just a description) since that's what's needed for real review. **Do not assume a Higgsfield `media_upload`/CDN URL is publicly viewable — it isn't (confirmed on the Pub Crawl side: gave Ash "Access denied").** Deliver via a plain public link instead (e.g. push the file from the sandbox to an anonymous file host like tmpfiles.org) — that specific action needs a one-time nod from Ash the first time per session since it publishes to a third-party host; he approved it 2026-08-31 for this use. Say plainly that the link is temporary/unlisted and may expire. Nothing goes live without an explicit approval reaction/reply — this is the "Ash approval required: publishing social content" rule from `CLAUDE.md`, not optional even for on-brand content. Also be upfront that frame-by-frame visual review by the agent itself is still not possible (network policy blocks pulling image/video bytes back into this session) — the scene analysis in step 3 is real visual understanding, but it isn't the same as watching the final render; always ask Ash to eyeball it before approving.
5. Once (and only once) Ash approves a specific piece in that thread, publish it and log it to "Incidenti e interventi" (`455a9b8c-37db-4b92-96bf-2f0dd0aee514`) as a Deploy entry, Sito = Tour.
6. If a week produces nothing (no usable real footage, no clear hook, no approval yet on last week's batch), log that too — an empty week is still a logged outcome, not silence.
7. Before closing: this agent is closest to what performs and what doesn't on the Wine Window side — if a real content idea surfaces beyond the standard angles (a trend, a format worth trying, something a competitor's doing), log it as an Idea per `CLAUDE.md` instead of just letting it pass. Only when there's something real to say.
